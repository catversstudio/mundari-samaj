# Mundari Samaj

> **Our Language. Our Identity. Our Heritage.**

**Mundari Samaj** is a [Catvers Studio](https://github.com/catversstudio) project — a global platform for the **Mundari language**, its own script **Mundari Bani**, and Munda culture, traditions and heritage.

🌐 **Live site:** https://mundarisamaj.pages.dev

## What's inside

- **Language** — Mundari Bani script with its full alphabet chart, grammar notes and beginner lessons
- **Dictionary** — a searchable Mundari dictionary, with Mundari Bani script beside every Mundari word
- **Culture & History** — festivals, identity, movement and resources
- **Community** — stories, voices and contributions from the community

## Editorial principle

Content is published only when verified from reliable sources. Anything still being checked is honestly marked **"Research in progress"** on the site.
